# 개발 구조와 다음 단계

## 이번 이식의 범위

원본 HTML의 CSS, Base64 초상화, 정적 데이터, 추첨 규칙, 저장 입출력을 별도 파일로 옮겼습니다. 초상화는 PNG 파일로 추출하여 브라우저가 독립적으로 캐시할 수 있게 했습니다. Vite가 경로 변환과 배포 산출물 생성을 담당합니다. 게임 밸런스와 콘텐츠 범위는 원본을 유지합니다.

화면과 턴 로직은 아직 `src/app.js`에 함께 있습니다. 서로 참조하는 함수들을 섣불리 나누어 전역 상태나 초기화 순서가 깨지는 것을 피하고, 현재 동작을 검증한 뒤 점진적으로 분리할 기반을 마련했습니다. React나 백엔드는 사용하지 않습니다.

## 상태와 실행 흐름

- 시작할 때 저장을 읽고 기존 운명/추첨 버전을 확인합니다.
- 화면 상태는 `fate`, `character`, `encounter`, `world`입니다.
- 시작 기연과 여정은 처음 결정할 때 저장하여 새로고침으로 재추첨되지 않게 합니다.
- `worldAction`, `martialOperation`, `enrollAcademy`가 행동을 처리하고 `finishWorldTurn`에서 시간을 진행합니다.
- `finishWorldTurn`은 야간 식량 소비, 회복, 무공 숙련 동기화, 돌발 사건 생성, 저장, 렌더링을 처리합니다.
- 돌발 사건은 대기 중인 사건의 토큰을 검사한 뒤 선택을 한 번 적용합니다.
- 14회 행동 이후 문파 방문이 열리며, 기존 행동도 계속 사용할 수 있습니다.

저장 키 `jianghu-fate-v1`은 유지합니다. 저장 스키마를 확장할 때는 기존 `rulesVersion`, `artVersion` 이관과 함께 버전별 마이그레이션을 추가하세요. 현재 여정 데이터 전체에 대한 스키마 검증은 없습니다.

## 권장 후속 개발 순서

1. **문파 콘텐츠:** 내문 승급, 공헌 소비, 상위 전승, 임무와 사부·동료 관계.
2. **턴 엔진 분리:** DOM을 참조하지 않는 `applyAction(state, action)` 형태로 자원·시간·성장을 처리하고 화면은 결과를 렌더링하도록 변경.
3. **재능·약점 효과:** 문자열 조건 대신 식별자와 효과 테이블로 성장량·비용 보정 연결.
4. **진행 안내:** 주간 결산, 문파별 목표와 독행 퀘스트.
5. **전투 확장:** 필드 전투, 다양한 적 패턴, 상태 이상, 장비와 무공별 효과.
6. **장기 진행:** 문파별 수련, 탐색 지역, 퀘스트, 성향과 단서의 활용처.

## 검증

`npm test`는 모든 능력치 추첨 티켓의 등급 경계, 기연 확률 분포, 사건 ID와 선택지의 기본 유효성, 저장 호환성을 검사합니다. 확률 표본 추정 대신 티켓 0–99를 전수 확인합니다.

`npm run test:e2e`는 프로덕션 빌드를 대상으로 데스크톱/모바일에서 생성, 보관·교환, 기연, 학관, 수련, 사건 선택, 새로고침 복원, 7일 완료, 이미지 로딩, 가로 넘침, 추첨 한도를 검사합니다. 검사는 모션 감소 설정으로 실행하므로 긴 소환 연출과 효과음의 체감 품질은 수동으로도 확인해야 합니다.

## 비무·수련·입문 v0.2

`src/game/progression.js`는 DOM 없이 비무의 다음 상태를 계산합니다. `src/progression-ui.js`는 기존 턴 엔진과 연결해 시작 비용을 지불하고, 완료 시 행동 1회와 보상을 적용합니다. 진행 중인 비무·수련은 다른 자원 행동과 무공 교체를 잠급니다. 중단·패배도 행동 1회를 사용하고, 전투 종료 상태에서는 추가 보상이 발생하지 않습니다.

- 내공량은 기존 `journey.inner`를 사용합니다. 비무의 `qi`는 별도 값이며 대련 시작 시 최대치로 회복합니다.
- 캐릭터 경지는 `journey.progress.realm`, 소속은 `progress.sect`에 보관합니다. 기존 저장은 이 객체만 초기화하여 이어갑니다.
- 삼류: 내공량 15 / 공격 무공 숙련 20. 이류: 60 / 50. 일류: 150 / 80. 돌파 비용은 기력 20과 행동 1회이며 확정 성공입니다.
- 화산은 공격 +2, 무당은 전용 심법의 내공 성장, 소림은 비무 체력 +12로 구분합니다. 외공 숙련은 체력·방어, 보법 숙련은 방어에 반영됩니다.
- 문파 입문 시험은 현재 모두 비무를 기본으로 사용합니다. 화산은 공격, 무당은 낮은 체력과 균형, 소림은 높은 체력으로 상대 수치를 달리합니다. 문파별 별도 시험 미니게임은 후속 확장 대상입니다.
- 문파의 선택 사건은 모두 입문 제안으로 이어지되 평가 문구가 달라지고, 수락하면 입문 기록을 남깁니다. 성향 점수로 정답을 고정하지 않습니다.
- 내문 승급·고급 무공·필드 전투·공헌 소비는 아직 구현하지 않았습니다.

브라우저 검사는 세 문파 입문·전수·수련, 기존 7일 저장 이관, 비무 도중 복원, 다른 행동 잠금, 경지 돌파, 보상 중복 방지, 중단 후 재도전을 포함합니다.
