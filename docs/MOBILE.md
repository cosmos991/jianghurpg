# 모바일 행동 중심 화면

760px 이하에서 실제 게임의 여섯 행동(무공 수련·운기조식·품팔이·탐색·휴식·식량 구입)은 그대로 표시합니다. 시대·날짜, 경지·문파·기력·은전·식량, 추천 목표 하나와 최근 결과 한 줄을 먼저 보여줍니다. 행동 조건이나 수치는 바꾸지 않았습니다.

상세 패널은 성장(상태·소지품·장기 수련 및 무공), 문파·비무, 기록(성향·일지) 메뉴로 엽니다. 메뉴를 바꾸면 다른 묶음은 접히지만 입력값과 게임 진행은 유지됩니다. 각 제목을 직접 눌러 여러 묶음을 열 수도 있습니다. 시작 인연 다시 보기는 기록으로 옮겼습니다.

추천 목표의 ‘열기’는 필요한 묶음을 열고 해당 위치로 이동합니다. 학관 입학 후 무공 선택과 같은 기존 안내도 접힌 패널을 먼저 엽니다. 비무·시험·문파 입문·단기 수련 또는 중단된 장기 수련은 진행이 숨지 않도록 관련 묶음을 자동으로 엽니다. 돌발 사건 팝업은 기존 동작을 유지합니다.

PC에서는 상세 패널을 모두 펼쳐 보여주며, 모바일↔PC 크기 변경 시 표시 상태를 다시 맞춥니다. 묶음의 접힘은 게임 저장이나 보상에 영향을 주지 않습니다. 상세 일지의 중복 낭독을 피하려고 모바일에서는 최근 결과만 실시간으로 알립니다.
