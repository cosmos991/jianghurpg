# 세계 편집실

배포 주소: https://jianghurpg.vercel.app/admin/

게임과 같은 사이트의 별도 관리자 화면입니다. 관리자 화면은 Supabase에서 실제 초안 데이터를 읽고 저장합니다. 게임 플레이의 20년 시대 진행과 점수 지급은 아직 연결하지 않았습니다.

## 처음 접속

1. **처음 이용하시나요? 계정 만들기**를 누릅니다.
2. 관리자 허용 목록에 등록한 이메일과 새 비밀번호(10자 이상)를 입력합니다. Supabase 관리 사이트 계정과는 별개의 **이 게임 전용 계정**입니다.
3. 받은 확인메일로 이메일을 인증합니다.
4. 로그인하면 편집 화면이 열립니다.

메일 확인 링크가 열리지 않으면 화면의 **확인메일 링크가 열리지 않을 때**를 열고 메일의 확인 버튼 링크 주소를 붙여 넣습니다. 앱은 프로젝트의 가입 확인 링크만 허용하며, 다른 사이트에 요청을 보내지 않고 Supabase `verifyOtp`로 인증합니다.

일반 가입 계정은 편집할 수 없습니다. 이메일 인증을 마쳤고 DB의 비공개 관리자 허용 목록에 있는 계정만 편집할 수 있습니다. 관리자 추가는 공개 화면에서 할 수 없으며, 소유자가 DB에서 별도로 등록해야 합니다.

Supabase 기본 메일 발송은 제한이 있습니다. 메일 발송 대상 오류가 나면 프로젝트 소유자가 Supabase의 Auth 이메일/SMTP 설정을 확인해야 합니다. 앱이 인증을 우회하거나 관리자 권한을 첫 가입자에게 부여하지 않습니다.

## 편집

- **시대의 배경:** 이름·설명·기간·설정 버전
- **과제와 점수:** 이름·설명·완료 조건·연결 대상·점수, 과제 추가/삭제
- **결과와 보상:** 점수 구간·설명·명성·공헌·전승 보상·필수 과제, 결과 추가/삭제
- **초안 저장:** 최소 입력 조건을 검사해 저장합니다. 합계가 100점이 아니어도 저장할 수 있습니다.
- **검사 후 적용:** 합계 100점, 결과 구간 0~100 전체, 필수 과제 참조를 검사하고 공개합니다.

조건과 보상은 지원하는 목록에서 선택합니다. 영어 ID는 자동 관리됩니다. 과제 삭제 시 결과의 필수 과제 참조도 함께 제거하며, 저장 전에는 DB를 바꾸지 않습니다.

이미 공개된 설정을 초안으로 저장하면 일반 조회에서 숨겨지므로 확인을 받습니다. 공개 버튼의 ‘적용’은 **카탈로그 공개**를 뜻합니다. 아직 구현하지 않은 게임의 시대 진행 기능이 자동 생기는 것은 아닙니다.

## 저장과 충돌

`save_era_editor_catalog` RPC가 하나의 트랜잭션으로 시대·과제·결과를 저장합니다. 실패하면 모든 변경이 롤백되고 화면 입력은 유지됩니다.

로드한 `updated_at`과 현재 DB의 값이 다르면 저장을 거부합니다. Supabase 관리 화면에서 과제·결과를 직접 바꾼 경우에도 부모 시대의 갱신 시간이 바뀌어 충돌을 감지합니다. 충돌 시 변경 내용을 메모한 뒤 **다시 불러오기**로 최신 데이터를 확인합니다.

## 권한 구조

- `jianghu_private.era_admin_emails`: 클라이언트 읽기·쓰기 불가
- `is_era_admin`: 인증된 사용자 ID와 현재 `auth.users.email`, `email_confirmed_at`을 소유자 권한으로 검사하는 제한된 내부 함수
- 공개 RPC: `era_admin_access`, `era_editor_catalog`, `save_era_editor_catalog`
- 실제 테이블 변경은 로그인한 사용자 권한과 관리자 RLS로 제한
- 서비스 키·관리자 비밀번호를 브라우저 번들에 넣지 않음
- `user_metadata` 또는 브라우저가 보낸 이메일로 권한을 판단하지 않음

## 로컬 실행

`.env.example`을 `.env.local`로 복사한 뒤 프로젝트의 URL과 **publishable 키**를 입력합니다. secret/service_role 키는 사용하지 않습니다.

```text
VITE_SUPABASE_URL=https://<project-ref>.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

`npm run dev` 후 `/admin/`으로 접속합니다. Vercel Production에는 실제 프로젝트의 공개 연결 설정을 등록했습니다. CI는 테스트용 공개 URL과 키를 쓰고 브라우저 테스트가 네트워크 응답을 가로채며 실제 계정이나 이메일을 생성하지 않습니다.

## 검증 범위

- DB 검사: 인증된 관리자/일반 계정/미인증 계정 권한, 초안 접근, 원자적 저장과 롤백, 공개 검사, 수정 충돌
- 브라우저 검사: 모바일·데스크톱 편집, 초안 저장·복원, 잘못된 합계 차단, 결과 적용, 권한 없는 계정 차단, 실패 시 입력 보존
- 실제 Supabase: 관리자 허용 목록과 정책 적용, 비인증 관리자 접근 거부, 보안·성능 Advisor 확인

브라우저의 인증·저장 응답은 테스트용으로 시뮬레이션합니다. 실제 관리자 이메일 인증과 첫 비밀번호 설정은 계정 소유자가 직접 진행해야 합니다.
