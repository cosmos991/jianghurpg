# 시대 등장

강호에 진입하면 공개된 Supabase 시대 설정을 한 번 읽어 현재 여정에 복사합니다. 시작일은 현재 턴이고, 1년은 기존 달력의 360일입니다. 이후 관리자 편집은 이미 시작한 시대에 영향을 주지 않습니다.

전체 화면에는 시대명, 소개, 기간, 실제 시작·종료일을 표시합니다. 건너뛰기, Esc, 입장 버튼으로 닫고 상단의 ‘시대 다시 보기’로 재생할 수 있습니다. 기본 효과음은 꺼져 있으며 동작 줄이기 설정을 존중합니다. 작은 화면에서는 본문을 스크롤해도 입장 버튼이 남습니다.

공개 설정이 없거나 연결에 실패해도 일반 행동을 계속할 수 있으며 다시 불러올 수 있습니다. 게임 전용 공개 RPC는 보안 호출자 권한과 기존 RLS를 적용하고 초안을 반환하지 않습니다.

현재 범위는 등장 연출과 시대 시간 표시입니다. 과제 점수 집계, 결과 보상, 20년 종료 기록 및 다음 시대 전환은 아직 연결하지 않았습니다.

## 1단계: 유형과 템플릿 추첨 테스트

관리자 편집실의 **00 시대 추첨 테스트**에서 사용할 수 있습니다. 로그인 후 고정 시드로 추첨하거나 새 시드를 생성하고, 1,000회 분포를 확인합니다. 후보는 아직 로컬 테스트 데이터이며 Supabase에 저장하거나 실제 여정에 적용하지 않습니다.

- 유형: 마교의 준동 / 비급의 행방 / 정파의 분열, 각각 가중치 1.
- 유형마다 템플릿 2개, 각각 가중치 1. 전체 랜덤이면 유형은 1/3, 유형 안의 템플릿은 1/2, 최종 템플릿은 1/6 확률입니다.
- 유형을 지정하면 해당 유형 안에서만 추첨합니다. 빈 후보, 중복 식별자, 잘못된 과제·결과 구성과 가중치는 오류로 처리합니다.
- 템플릿에는 20년 기간, 과제 100점, 0~100점의 연속된 결과 구간을 미리 정의했습니다. 추첨은 수치나 보상을 변경하지 않습니다.
- 단일 추첨 재현 기준은 `era-draw-v1` 알고리즘 + 후보 버전 + 시드 + 유형 선택입니다. 시드는 앞뒤 공백을 제거한 1~128자입니다.
- 분포 검사는 첫 번째에 입력 시드를 쓰고 이후 서로 다른 파생 시드를 사용합니다. 하나의 시드를 1,000번 반복하는 검사가 아닙니다. 화면의 각 비율은 전체 1,000회 기준이며 실제 비율에는 표본 오차가 있습니다.
- 최근 5회 이력은 화면 메모리에만 유지합니다. 게임 진행, 관리자 문서, 초안/공개 상태를 변경하지 않습니다.

후보 데이터: `src/game/era-candidates.js`. 후보나 순서를 바꾸면 `ERA_POOL_VERSION`을 올리고, 추첨 알고리즘을 바꾸면 알고리즘 버전을 올립니다. 다음 단계에서 검토한 후보를 실제 데이터 저장소 및 게임 시작 흐름과 연결합니다.

## 2단계: 짧은 사건과 성장 반복 테스트

편집실의 **01 짧은 사건 테스트**에서 시작합니다. 시대 유형과 시드, 시작 능력치를 선택하면 해당 유형의 템플릿을 추첨해 테스트 시대를 엽니다. 새로고침 시 초기화되는 메모리 전용 테스트이며 실제 캐릭터, 게임 저장, Supabase 문서를 수정하지 않습니다.

- 마교·비급·정파 분열의 각 시기마다 8개, 총 72개의 시기별 독립 사건을 넣었습니다. 사건은 선택 한 번으로 끝나며 후속 사건 체인을 만들지 않습니다.
- 무공 수련은 하루에 무력 +2·내공 +1, 독서와 교류는 지혜 +2·처세 +1, 기연 탐색은 하루 25% 확률로 내공 +4입니다. 이 수치는 테스트용이며 능력치 상한은 100입니다.
- 하루마다 활동 성장을 반영한 뒤 사건을 검사합니다. 사건 다음 날은 발생하지 않고, 이후 매일 35% 확률로 추첨합니다. 따라서 실제 전체 날짜 대비 발생률은 35%보다 낮습니다. 최근 4개 사건은 제외합니다.
- 7일 진행도 하루씩 검사하며 첫 사건에서 즉시 멈춥니다. 사건이 남아 있으면 시간과 활동을 진행할 수 없습니다.
- 능력치와 은전을 만족한 선택지만 사용할 수 있습니다. 선택 전에 보이는 수치는 실제로 검증되며, 선택 후 비용·과제 점수·마도·타락을 즉시 반영합니다. 확률 판정이나 별도 비무 화면은 없습니다.
- 모든 사건에는 조건 없는 ‘지나친다’가 있습니다. 빈곤하거나 능력치가 낮아도 진행이 막히지 않습니다.
- 사건은 지정된 과제에만 점수를 더하거나 뺍니다. 과제별 0~25점, 총 0~100점으로 제한하며 상·하한 때문에 실제 변화가 작아지면 실제 반영값을 결과에 표시합니다.
- 마도 선택의 타락 수치는 기록만 하는 프로토타입입니다. 타락 페널티와 실제 게임의 마도 성장 규칙은 아직 연결하지 않았습니다.
- 같은 시드·시작 설정·활동·선택은 같은 결과를 재현합니다. 20년(7,200일)이 지나면 마지막 날의 사건을 처리한 뒤 테스트를 마칩니다. 결과 등급은 표시하지만 실제 보상을 지급하지 않습니다.
- 선택에는 사건 토큰을 검사하므로 완료된 사건이나 오래된 선택을 다시 처리할 수 없습니다. 시작 설정은 진행 중 잠기며 ‘설정으로 돌아가기’는 진행을 초기화합니다.

빠른 비교: 기본 시드 `event-001`과 마교 유형에서 무공 수련 7일 진행을 누르면 **4일째 ‘계곡의 집결지’**에서 멈춥니다. 약한 인물과 강한 인물로 같은 설정을 각각 시작해 선택지와 과제 점수의 차이를 확인할 수 있습니다.


## 3단계: 시기별 난이도

테스트 시대는 20년 기준으로 초반 1~5년(0~1,799일), 중반 6~12년(1,800~4,319일), 후반 13~20년(4,320일 이후)으로 나뉩니다. 자연스럽게 날을 보내도 현재 시기의 사건만 추첨합니다. 각 시기의 사건은 같은 계열의 상황이 확대되는 별도 제목·본문을 갖습니다. 전체 후보는 3유형 × 3시기 × 8개 = 72개입니다.

- 주요 선택의 무력·지혜·처세·내공 요구치는 초반 15~30, 중반 35~60, 후반 65~90입니다. 작은 기여에는 이 범위를 적용하지 않습니다.
- 주요 능력치 선택의 기여는 뒤로 갈수록 커집니다. 은전으로 지원하는 선택은 후반에 비용이 늘지만 기여는 최대 3점입니다.
- 모든 사건에 조건·비용 없는 작은 기여를 넣었습니다. 초반 +3점, 중반 +2점, 후반 +1점으로 제한합니다. ‘지나친다’도 그대로 남습니다.
- 마도 선택은 일반 능력치보다 낮은 요구치(초반 10~20, 중반 25~35, 후반 40~50)를 갖지만 후반일수록 타락 대가가 커집니다. 타락 페널티 자체는 아직 프로토타입에 연결하지 않았습니다.
- **같은 능력치로 시기 비교** 버튼은 테스트 전용입니다. 진행 중인 사건을 같은 계열의 해당 시기 사건으로 교체하고 시기 시작일로 이동합니다. 능력치·은전·성과·타락은 유지하며 건너뛴 기간의 수련·기연·보상은 계산하지 않습니다. 진행 중 사건을 교체할 때도 보상을 주지 않습니다.
- 이동할 때마다 선택 토큰을 새로 발급하므로 교체 전 사건의 선택을 재사용할 수 없습니다. 시기를 바꾼 뒤에는 일반 하루/7일 진행을 이어갈 수 있습니다.
- 테스트 수련 속도는 빠른 비교를 위한 기존 값입니다. 이 속도를 실제 게임의 20년 성장 균형으로 확정한 것은 아닙니다. 과제별 25점 상한도 그대로 유지합니다.

빠른 비교: 강한 인물(주요 능력치 45~50)로 시작한 뒤 초반·중반·후반 버튼을 차례로 눌러 봅니다. 능력치는 그대로지만 후반의 주요 선택은 잠깁니다. 후반에도 ‘작은 기여’를 선택하면 +1점을 얻을 수 있습니다.

## 4단계: 문파·제자 등급·특수 임무

짧은 사건 테스트의 시작 설정에서 무소속 또는 화산·무당·소림을 고릅니다. 이 선택은 테스트 전용이며 실제 게임의 가입 상태를 바꾸지 않습니다.

- 외문 → 내문: 무공 수련 8일, 누적 공헌 12, 문파 주 능력치 30, 신임 15.
- 내문 → 핵심: 무공 수련 20일, 누적 공헌 40, 문파 주 능력치 55, 신임 35.
- 네 조건을 모두 충족해야 승급 버튼이 열립니다. 한 번에 한 등급만 오르며 공헌은 소비하지 않습니다. 사건 처리 중에는 승급할 수 없습니다.
- 외문/내문/핵심은 무공 수련 4/3/2일마다 주 능력치 +1의 문파 지원을 받습니다. 화산은 무력, 무당·소림은 내공을 지원합니다. 내부 누적치를 사용해 승급 직후 보너스가 중복 발생하지 않습니다.
- 특수 임무는 시대 유형 3종 × 제자 등급 3종의 9개 틀입니다. 소속 문파와 경쟁 문파 이름을 적용하고 시대 시기·관계에 따라 요구치가 달라집니다. 외문은 순찰·소문, 내문은 분쟁·조사, 핵심은 교섭·연합 작전을 맡습니다.
- ‘특수 임무 받기’로 직접 확인하거나, 일반 사건이 등장할 때 조건을 만족하면 40% 확률로 문파 임무가 대신 끼어듭니다. 실제 활동 3일 간격으로 받을 수 있고 진행 중인 사건이 있으면 새 임무를 받을 수 없습니다.
- 공동 조사와 중재는 시대 과제 및 문파 관계에 기여합니다. 경쟁 문파 압박은 공헌과 신임·은전을 더 얻지만 관계를 악화시키며, 특히 정파 분열 시대에는 시대 성과를 깎습니다. 조건 없는 작은 지원과 명령 거절도 가능합니다.
- 신임은 0~100, 문파 관계는 −100~100입니다. 경쟁 문파와 관계가 −30 이하면 적대해 교섭 요구치 +10, +30 이상이면 우호로 −5가 적용됩니다. 임무를 받을 때 조건을 확정합니다.
- 시기 비교는 수련 일수·활동 일수·공헌·관계를 올려주지 않으며 임무 대기 간격도 초기화하지 않습니다. 임무 교체 시 보상을 주지 않고 과거 선택은 다시 처리할 수 없습니다.
- 이 수련·승급 속도는 기능 확인을 위한 빠른 테스트 값입니다. 실제 게임의 20년 성장 수치와 연결한 최종 밸런스는 아닙니다. 아직 문파 고유 무공·장로 승급·전쟁 시뮬레이션을 추가하지 않았습니다.

빠른 확인: 소속 화산, 시대 정파의 분열, 강한 인물로 시작 → 특수 임무 받기 → 공동 조사 선택. 문파 공헌 +6, 관계 +12와 시대 과제 +6점을 확인합니다. 이후 수련과 임무를 이어가 내문제자로 승급하면 수련 지원과 임무 규모가 바뀝니다.

## 사건 팝업

시대 테스트의 돌발사건·문파 특수 임무와 실제 게임의 길 위 돌발사건은 메인 화면에 선택지를 펼치지 않고 모달 팝업으로 표시합니다. 새 사건은 자동으로 열리고, 선택하면 닫힙니다.

‘잠시 닫기’, Esc, 팝업 바깥 클릭은 사건을 해결하거나 보상을 지급하지 않습니다. 메인 화면에는 짧은 대기 안내와 ‘사건 확인’ 버튼만 남으며, 선택하기 전에는 시간 진행이 계속 잠깁니다. 다시 열면 같은 사건을 표시합니다. 실제 게임의 미해결 사건은 기존 저장 상태를 사용하므로 새로고침해도 다시 열립니다. 편집실 테스트는 기존처럼 새로고침 시 초기화됩니다.

모달은 키보드 초점과 배경 클릭을 격리하고, 닫힐 때 초점을 돌려줍니다. 모바일에서는 화면 높이 안에서 내용과 선택지를 스크롤하며 닫기 버튼이 상단에 남습니다. 기존 사건 조건·선택 결과·문파 수치는 변경하지 않았습니다.

## 5단계: 20년 성장 비교

편집실의 **02 20년 성장 비교**는 실제 게임과 분리된 수치 검증 도구입니다. 시작 능력치, 집중 능력치, 시대 유형, 수련·기연·생계 비율을 설정한 뒤 무소속·화산·무당·소림을 같은 조건으로 계산합니다. 저장이나 공개 설정 변경은 하지 않습니다.

기본 가정은 수련 60일당 집중 능력치 +1, 해당 문파의 수련 효율 +20%, 탐색 하루당 기연 확률 0.5%와 발견 시 집중 능력치 +1입니다. 다른 능력치는 무력·지혜·처세 15, 내공 10, 마도 0으로 고정합니다. 능력치 상한은 100입니다. 화산은 무력, 무당·소림은 내공 수련에만 보정합니다. 소림과 무당은 이 기준 모델에서는 같은 보정을 갖습니다.
