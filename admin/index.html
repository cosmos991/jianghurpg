시대 추첨 테스트

미리보기

시대 유형을 먼저 뽑고, 그 유형 안에서 템플릿을 뽑습니다. 테스트 후보는 3유형·6템플릿이며 모든 가중치는 1입니다. 실제 게임이나 Supabase 설정에는 적용하지 않습니다.

시드값은 추첨을 재현하는 번호입니다. 같은 시드·유형·후보 버전이면 같은 결과가 나옵니다. 유형을 직접 고르면 그 안의 템플릿만 추첨합니다.

      짧은 사건 테스트

      미리보기

      시대 시작 → 수련·기연 → 가끔 사건 → 선택 한 번 → 과제에 반영. 실제 캐릭터와 Supabase 설정에는 영향을 주지 않는 테스트입니다.

      시작 설정

      같은 능력치로 시기 비교

      테스트 전용 이동입니다. 진행 중인 사건을 해당 시기의 비교 사건으로 교체합니다. 능력치·은전·성과는 유지하며, 건너뛴 날의 성장·보상은 받지 않습니다.

      문파 안에서의 성장

      등급과 승급 기준

      외문 → 내문: 무공 수련 8일, 공헌 12, 문파 주 능력치 30, 신임 15.
      내문 → 핵심: 무공 수련 20일, 공헌 40, 문파 주 능력치 55, 신임 35.

      특수 임무는 실제 활동 3일 간격이며 일반 사건 사이에도 끼어듭니다. 적대 관계면 교섭 요구치가 오르고, 우호 관계면 낮아집니다. 시기 이동은 수련·공헌·임무 대기 일수를 올려주지 않습니다.

      선택을 기다리는 사건이 있습니다. 선택 전까지 시간은 멈춥니다.
